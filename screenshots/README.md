## 🎨 Panduan Presentasi Canva (Docs-to-Deck)

Bagi Anda yang ingin mengonversi dokumentasi ini menjadi **Slide Presentasi Canva** secara instan tanpa khawatir gambar diubah/digenerate ulang oleh Canva AI:

1. Buat dokumen baru di Canva: **Canva Docs**.
2. Salin teks per bab di bawah ini ke Canva Docs tersebut.
3. Tempelkan (*drag-and-drop*) file gambar PNG yang sesuai dari folder `screenshots/` di bawah masing-masing judul.
4. Klik tombol **Convert** / **Ubah ke Presentasi** di pojok kanan atas Canva Docs.
5. Selesai! Slide presentasi profesional akan tersusun rapi dengan gambar asli.
